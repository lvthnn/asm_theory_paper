# Numerical study scripts for "A high-dimensional perspective of assortative mating: definition, dynamics, and limiting results".
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.24447073.svg)](https://doi.org/10.5281/zenodo.24447073)

This repository contains the scripts used for the numerical study of the manuscript "A high-dimensional perspective of assortative mating:
definition, dynamics, and limiting results". The repository is organised as follows:

* `simulations.lua` – The [knoop](https://github.com/knoop-dev/knoop) configuration file used to perform simulations to validate theory.
  In order to run these, you will need to install knoop.
* `scripts/` – R scripts used for theoretical computations, and to compare these with simulated data.
* `results/` – Results of numerical computations. `*.h5` files are generated by knoop, and `*.Rds` files are saved from R sessions.
* `img/` – Figures generated by the above.
